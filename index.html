5. Draw / edit profile

The orange rectangle is the entered Length × Width reference frame. Draw the actual tool shape; it does not have to be drawn to screen scale. Points can be dragged. Use Add point, delete a point or delete a range, then reconnect automatically. Each segment can independently be Straight or Curved.

Undo: Undo reverses only your edits, newest first. The generated/imported outline is the baseline and is never removed by Undo.
Tip: touching the orange reference-frame border does not add a point. Point editing is explicit: drag an existing point to move it, or use Add point to insert one. A normal tap on an existing point selects it for dragging rather than adding another point.

7. Engineering geometry check

The check is performed after scaling and curve sampling, before STL export. It checks the profile and cleared profile for self-intersection, envelope limits and finger-relief placement.

Optional: Saved Profiles

This section is optional. Use Export Profile only if you want to save the current profile for reuse later. Use Import Profile to select one of your previously exported profile JSON files. JSON is a profile backup/reuse file — it is not the STL used for printing.

9. STL test export

Exports a positive pocket-cut volume for the tray. The main pocket occupies the configured depth from the tray top, and the finger relief occupies only its shallower upper zone. This stepped geometry is suitable as a reference/boolean cut volume.
